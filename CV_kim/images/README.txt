이 폴더에는 웹사이트에서 사용하는 이미지 파일을 넣습니다.

필수 파일명

1. profile.png
   - PROFILE의 프로필 이미지입니다.

2. current_position_logo.png
   - PROFILE의 CURRENT POSITION 영역에 표시되는 기관 로고입니다.

3. namecard_kor.png
   - CONTACT 영역의 한국어(Kor) 명함 이미지입니다.

4. namecard_eng.png
   - CONTACT 영역의 영어(Eng) 명함 이미지입니다.

이미지 파일이 존재하지 않으면 해당 이미지 영역은 자동으로 숨겨집니다.
명함 이미지는 실제 가로/세로 비율을 감지하여 레이아웃에 맞게 표시됩니다.
